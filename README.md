# 🎮 Minecraft Server Status Checker 🌐

A feature-rich web application to monitor and analyze Minecraft servers with advanced diagnostics.

## ✨ Key Features

### 🔍 Server Detection
- Dual edition support (Java & Bedrock)  
- Instant IP resolution from hostnames  
- Port detection with smart defaults  
- IPv4/IPv6 compatibility  

### 📊 Status Analytics
- Real-time online/offline monitoring  
- Uptime detection  
- Version compatibility checking  
- Player capacity analytics  
- Server software detection  

### 🛠️ Advanced Tools  
- Connection latency testing  
- Player list visualization  
- Avatar previews  

### 🎨 Premium Design
- Responsive mobile-first UI  
- Animated status indicators  
- Dark/light mode ready  
- Minecraft-style theming  
- Accessibility optimized  

## 🚀 Installation

```bash
# Clone repository
git clone https://github.com/yourusername/minecraft-status-checker.git
cd minecraft-status-checker

# Run with Python
python3 -m http.server 8000

# Or with Node.js
npx serve
